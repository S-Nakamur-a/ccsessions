# 0009 · 表示順は名前 → id の安定順

採用 · 2026-07-25

## 文脈

`store::list_live` は「直近に動いたセッション」を選ぶために `updated` の降順で返す。
選抜の基準としてはそれで正しい。

## 決定

**選抜（recency）と表示順（stability）を分ける。** `ccsessionsd` は受け取った一覧を
プロジェクト名 → id の辞書順に並べ直してから描く（`sort_for_display`）。
`ccsessions list` は recency 順のまま（CLI ではそちらが有用）。

## 理由

`updated` は hook が飛ぶたびに変わるので、recency 順をそのまま表示に使うと
**動いたセッションが毎回先頭へ移動し、隣の生き物と場所を入れ替える**。
常時視界に入るものとして落ち着かない。

名前が同じプロジェクトが複数あっても id で決定的に並ぶので、同じセッション集合なら
常に同じ配置になる。

## 影響

ホバー中のカードが指すセッションは**索引ではなく id で追跡する**。並びは安定でも
セッションが増減すれば索引はずれ、カードが隣のセッションの内容を出したまま残る。
