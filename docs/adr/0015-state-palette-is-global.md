# 0015 · 色・アニメ・グリフは顔ごとに変えられない

採用 · 2026-07-26

## 文脈

顔をデータで足せるようにすると（[0014](0014-faces-as-data.md)）、「色も自分で
決めたい」が自然に出てくる。

## 決定

**顔が決めてよいのはシルエット・目・線画・寸法だけ。** 色（シアン＝作業中、
琥珀＝判断待ち …）とアニメ（bob / hop / drift / breath）とグリフは全顔で共通にする。

顔が状態を表現する余地は**目の形・開き具合・向き**に閉じる。

## 理由

このツールの価値は「見れば状態が分かる」こと。色と動きの対応は読み取りやすさの核で、
顔ごとに変えられるようにするとその一貫性が壊れる。

目に閉じても表現は足りる。たとえばヘルメットの顔は「スリットの縦の開き具合」で
判断待ちとアイドルを表しており、同じ枠を全顔に一般化してある。

## 影響

- パレット・アニメ仕様は `ccsessions-core/src/face/palette.rs` と
  `ccsessionsd/src/theme.rs` にある。顔の TOML からは触れない。
- 顔は状態ごとに**目の縦横の倍率・横ずれ・色（4 択）・グロー・瞬き**だけを
  上書きできる。書かなければ既定ルールが効くので、投稿者はシルエットだけ書けば
  6 状態すべてが成立する。
- 将来「色も差し替えたい」が来たら、それは *theme pack* という別概念にする。
