# 0017 · 顔の bar の体の高さは 22pt 以下

採用 · 2026-07-26

## 文脈

顔が自分で寸法を名乗れるようになったので（[0014](0014-faces-as-data.md)）、
「メニューバーに収まる」を投稿者に守らせる仕組みが要る。

## 決定

顔のバリデータが `size.bar.h <= 22` を課す（`face::validate::MAX_BAR_BODY_H`）。
**この数字と理由をバリデータのエラーメッセージと `faces/README.md` に直接書く**
（「なぜ入らないのか」が投稿者に分かるように）。

## 理由

上限を決めるのは**一番低いメニューバー**であって、作者の Mac ではない。

- ノッチ機（33pt）だけを見るなら、グリフ用の 12pt を載せても 21pt まで許せる。
- しかし**非ノッチ画面は 24pt** しかなく、外部モニタにフォーカスを移すだけで
  そちらが基準になる。24pt ではグリフを体に重ねる段階に落ちるので
  （[0010](0010-narrow-band-folds-inward.md)）、必要な高さは体そのものになる。
- したがって上限は `24 − 上下の余裕 2 = 22pt`。ノッチ機ではさらにグリフ用の 12pt が
  上に載るが、そちらは 33pt あるので通る。

## 影響

検証は数値の比較ではなく、**サポートするメニューバー高（24 と 33）の両方で
レイアウトが収まるか**のループで行う。実機を持ち替えずに機種を再現できるのが
`geometry` / `layout` を純関数に保っている利点。
