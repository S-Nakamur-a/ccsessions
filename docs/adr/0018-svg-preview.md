# 0018 · SVG プレビューを目視の代わりにする

採用 · 2026-07-26

## 文脈

開発環境に画面収録権限が無く、`screencapture` が失敗する。`ccsessionsd` が画面
ジオメトリとホバー対象を stderr に出しているのはそのためで、顔についても
同じ手段が要る。

## 決定

`FaceSpec` から SVG を描く純関数のレンダラを `ccsessions-core/src/face/svg.rs` に置き、
CLI (`ccsessions face render` / `gallery`) と Web UI の両方から使う。

## 理由

**同じ `FaceSpec` から CALayer と SVG の 2 経路で描くので、SVG は CALayer の忠実な
プレビューになる**（輪郭・目・線画は完全に同じデータと同じ解決関数から出る。
グローとアニメだけが SVG では静的な近似）。

得られるもの:

1. 投稿者が PR に SVG を貼れる。レビューが目視できる。
2. ギャラリーの出力を README に貼れば、顔の一覧がそのままドキュメントになる。
3. Mac を持っていなくても顔を作れる。

## 影響

- **ブラウザ側で顔を描き直さない。** JS で描くと 3 つ目の実装が生まれ、いずれ
  静かにずれる。Web UI は「選んで、返ってきた SVG を貼る」だけにしてある
  （[0020](0020-single-settings-entrance.md)）。
- グローとアニメが近似になることは受け入れる。形が合っていることの方が価値が高い。
