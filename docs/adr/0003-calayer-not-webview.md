# 0003 · 描画は CALayer 直描き。WebView は使わない

採用 · 2026-07-25

## 文脈

元のデザインは HTML/CSS で書かれている。そのまま `WKWebView` に載せれば写経の手間が
省ける。

## 決定

CALayer を直接組む。CSS の角丸プロファイルやアニメは Rust の定数・純関数へ写経する。

## 理由

- **常駐オーバーレイに WebView を置くと省電力性が壊れる。** このプロセスはログイン中
  ずっと生きているので、アイドル時 CPU 0.0–0.1% が要件。
- CoreAnimation にアニメを自走させれば、メインスレッドはポーリング間隔ごとに短く
  起きるだけで済む。**毎フレーム描画するタイマは足さない。**

## 影響

- CSS の `border-radius: 50% 50% 48% 48% / 58% 58% 42% 42%` のような指定は
  ベジェへ書き起こす必要がある。その知識は `ccsessions-core/src/face/` に閉じ込め、
  顔ごとの形は [0014](0014-faces-as-data.md) のとおりデータにした。
- レイヤは**作り直さず差し替える**。作り直すとアニメの位相がリセットされ、
  群れ全体が不自然に同期して揺れる。
